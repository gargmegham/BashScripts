# BashScripts

A collection of useful Bash scripts for various system administration and setup tasks.

## Scripts

- **FastAPI_VM_Setup.sh**: Script to set up a virtual machine environment for FastAPI development.
- **VM_SSH_ASCII_Art.sh**: Displays ASCII art upon SSH connection to a virtual machine.

## Usage

Each script can be run directly from the command line:

```bash
chmod +x script_name.sh
./script_name.sh
```
